# Inspirations

Every project we take an idea or code from, in the same commit that takes it
(AGENTS.md). Copied code keeps its licence notice.

| Project                                                                                                | Licence | What we take                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------------------------------------------ | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [GitHub Desktop](https://github.com/desktop/desktop)                                                   | MIT     | The product we match, behaviour only (no code, no artwork): its layout; the checkbox model of committing (lines checked from the gutter and hunk headers, amend loading the last message, co-authors, the summary prefilled from the merge message); discarding to a Trash folder named after the repository and date; `GIT_OPTIONAL_LOCKS=0` for background status; the conflict banner with Continue and Abort and sides named by branch; history and compare (unpushed marks, Undo putting the message back, merge files against the first parent, Behind/Ahead, `--mixed` reset, `-m 1` for merges); one account per host, the publish dialog and its private default, PRs with CI state and the finished-checks notification; submodules on clone; the sidebar's Recent section of three; its keyboard shortcuts (⌘1, ⌘2, ⌘T, Space to check the selected files) and editor list order; in the diff, asking before drawing a large one with a hard limit past it, line checking off while whitespace is hidden, and images side by side. |
| [Dhun](https://github.com/vivekg7/dhun)                                                                | GPL-3.0 | Our own project's repository conventions: numbered plans, hooks, `make` targets, the macOS package and build script layout. Same author; no GPL code is copied into this repo.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| [github/gitignore](https://github.com/github/gitignore)                                                | CC0-1.0 | The Go, Java, macOS, Node, Python, Rust, Swift and Xcode `.gitignore` templates offered when creating a repository (`Templates.swift`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [choosealicense.com](https://github.com/github/choosealicense.com)                                     | MIT     | The MIT, Apache-2.0, GPL-3.0, BSD-2-Clause, BSD-3-Clause, ISC and Unlicense texts with their `[year] [fullname]` placeholders; its notice is kept in `Templates.swift`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| [GitHub CLI](https://github.com/cli/cli)                                                               | MIT     | `gh auth setup-git`'s idea: an empty credential helper that resets the list for one host, then a host-scoped helper of our own. Idea only; no code.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
